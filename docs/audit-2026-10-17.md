# Pre-run audit, 2026-10-17

Independent review (Opus 5.5, xhigh effort) of the design, harness, specs,
acceptance packs and fixture at scaffold commit d8379cc, before the first
matrix run. Recommendation: no-go until the blockers are fixed.

## Blockers

B1. No PID namespace. CTF finds and kills cFS by command line across the
host (`pgrep -f "core-cpu1 --reset PO"`, `pkill -9`), so parallel runs kill
each other's cFS and CTF refuses to start while another run's cFS is alive.
Timeouts kill only pasta, orphaning claude, cFS and CTF inside the wrapper.
Fix: second wrapper layer `unshare -m -i -p -f --mount-proc --kill-child`;
start the wrapper in its own session and kill the process group on timeout;
re-verify with overlapping CTF runs.

B2. The answer key is readable by the agent. The pack is copied to
`<run_dir>/acceptance` and never removed; results and logs land in the run
dir; the harness checkout, other runs' solved repos and the packs'
reference solutions are all reachable by an agent with bypassPermissions.
Fix: mount tmpfs over the runs dir, harness checkouts and arms dir inside
the mount namespace and bind back only this run's `repo/` and `config/`;
never copy `selftest/`; grep transcripts after each run for leaks.

B3. The subagent-model factor and the A1 baseline are not enforced.
Built-in agents (general-purpose, Explore, Plan) inherit Opus in every arm;
the Agent tool's per-call `model` overrides frontmatter; Workflow, Skill,
SendMessage, ListAgents, RemoteTrigger, CronCreate, EnterWorktree are
exposed in all arms including A1. Spawn counting misses Workflow and Skill.
Fix: deny those tools everywhere; deny built-in agent types in A2-A9; set
`CLAUDE_CODE_SUBAGENT_MODEL` with `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1`
(probe that FORCE beats the per-call model); post-run validator that every
subagent request used the arm's model at effort high and no forbidden tool.

B4. Primary metric computed on a biased basis. (a) cost.py bills all cache
writes at the scenario price, so the default 1h scenario overcharges
subagents' 5m writes by 60 percent, penalising delegating arms. (b) The
aggregate medians over passed runs only; cap-hit and aborted spend is lost.
(c) Summing per-round CLI cost after `--resume` probably double counts.
Fix: add a "billed" scenario (5m writes at 5m price, 1h at 1h) as primary;
reconcile per round against the CLI within 1 percent; primary metric =
total billed spend over all attempts of an arm x task divided by passes,
with conditional median and attrition reported separately.

B5. The Task 4 pack depended on lcov, which is absent (being fixed: gcov).

## Major

M1. Run order `product(arms, tasks, reps)` confounds arm with calendar time
and load; parallel slots always hold the same arm x task. Fix: randomised
complete blocks with a recorded seed; different arms in parallel slots.

M2. Environment and CLI version uncontrolled: the child inherits the
launching Claude Code session's variables; `CLAUDE_CODE_PROMPT_CACHE_TTL`,
`CLAUDE_CODE_SUBAGENT_MODEL`, `CLAUDE_CODE_EFFORT_LEVEL` would silently
override arm settings; the auto-updating binary is not pinned. Fix:
environment allowlist, `DISABLE_AUTOUPDATER=1`, absolute versioned binary,
record version, harness SHA, spec and pack hashes, template HEAD.

M3. Each fresh config dir gets a new server-side experiment identity
(feature-flag bucketing). Fix: seed every run with one fixed `.claude.json`
identity, or at least record the assignment and check balance across arms.

M4. Arm-root copy is not allowlisted; stray files in one root change one
arm. Fix: copy only settings.json, CLAUDE.md, agents/ and assert nothing
else exists.

M5. Agent-caused faults become infra errors (uncaught exceptions in Task 1
and 3 packs, pack timeouts), dropping the run and its spend. Fix: per-check
exception capture; reserve exit 2 for pre-agent integrity problems; record
timeouts as failed rounds with spend.

M6. Subscription limits: any CLI error aborts the run and the matrix reruns
from scratch; long runs are cut more often, biasing toward short runs.
Fix: detect limit messages, sleep to reset, resume the same session with a
fixed neutral message, pause the matrix.

M7. Simulated-pause method unsound: gaps include agent working time;
pauses only at resume rounds; real request timestamps unused; subagent idle
time never converted between scenarios; one seed. Fix: compute question 3
offline from archived transcripts per thread with actual timestamps; apply
human idle gaps as an expectation; freeze and hash the gap file.

M8. n = 3 per cell cannot support per-cell claims (minimum two-sided
Mann-Whitney p = 0.10). Fix: pre-register contrasts; analyse log billed
cost with task fixed effects and the 4 x 2 factorial terms pooled across
tasks; bootstrap or permutation intervals; pass rate as a separate
outcome; if budget bites drop a whole subagent-model level; pilot first.

M9. Packs validated against one reference each; Task 2's hidden test
queues stub data buffers and desynchronises on an extra GetMsgId call;
Task 4's in-memory OSAL model covers a fixed API set; time-budget
exhaustion reaches the agent as a requirement failure. Fix: mutants plus an
independent correct implementation per pack; ten selftest repetitions
under parallel load; budget exhaustion as infra outcome; one retry of live
scenarios.

M10. The smoke run (old settings, old harness) is counted as a completed
cell. Fix: fresh runs dir; matrix and aggregate require matching hashes.

M11. Cost completeness unverified beyond A1 (compaction fork, workflows,
background agents may be outside the files cost.py reads). Fix: per-round
reconciliation plus a pilot with `--autocompact 100000`.

## Minor

Run ID reveals the arm (use a nonce); system prompt prefix is globally
cached so a small cross-run cache effect exists; token passed into packs
that run agent-written code; analysis errors leave status completed and
drop cost silently; no CLI timeout ceiling; spec and pack disagreements
(Task 4 header bytes and new-sequence-after-close tested but unstated;
Task 1 duplicate-suite rule and Task 2 HK layout stated but untested;
"commit the work" never tested); Task 1 is shorter than estimated and all
specs pin names, which structurally favours A1; Task 4 scratch on tmpfs;
acceptance timeout too tight for Task 4; CPU oversubscription and ccache
make timing arm-correlated; aggregate lacks attrition and hash checks;
layer 2 cannot be blind as run dirs and summaries reveal the arm; CTF
setup races on a missing cache and pip-installs from PyPI per run.

## What is sound

Deterministic arm generation; A2-A9 differ only in model and delegation
text; read-only agents have no write tools; auto-memory off; per-run config
dir with archived transcripts and atomic run.json; template matches the
committed fixture at the pinned commits; pip constraints pin everything;
acceptance contract validation and feedback ordering; cost core math and
dedup on A1; network, IPC, /dev/shm and uid isolation; no token in
artifacts; Task 3 stub design and live scenario; Task 4 black-box test;
disk use about 0.65 GB per short run.

## Decisions for the experimenter

Built-in agents in or out; WebSearch and WebFetch policy; whether main 1h
and subagent 5m TTL is intended (report a uniform-TTL counterfactual
alongside); whether to keep Task 1; the analysis plan and budget-cut rule.
